# 👨‍🏫 Кабинет учителя - Полный обзор

## 📌 Что это?

Полнофункциональная система для учителей, позволяющая:
- ✅ Регистрироваться и входить в систему
- ✅ Просматривать список учеников своего класса
- ✅ Анализировать прогресс каждого ученика
- ✅ Видеть детальную статистику по урокам и челленджам
- ✅ Отслеживать достижения и работы учеников

## 🎯 Основные возможности

### 1️⃣ Аутентификация учителя
- Отдельный экран входа для учителей
- Регистрация новых аккаунтов учителей
- Автоматическое перенаправление на кабинет после входа

### 2️⃣ Кабинет учителя
- Приветствие с именем учителя
- Список всех учеников класса в виде карточек
- Для каждого ученика видна сводка:
  - Имя и email
  - Количество пройденных уроков
  - Количество завершённых челленджей
  - Общее количество звёзд

### 3️⃣ Просмотр прогресса ученика
- Статистика (звёзды, уроки, челленджи, награды)
- Визуальные прогресс-бары по урокам и челленджам
- Детальный список звёзд по каждому уроку/челленджу
- Список полученных достижений
- Информация о работах в галерее

## 🔗 API Endpoints

### Для учителей (требуется токен)

#### Получить список учеников класса
```
GET /api/auth/teacher/class-students
Authorization: Bearer {token}
```

#### Получить прогресс конкретного ученика
```
GET /api/auth/teacher/student/:studentId/progress
Authorization: Bearer {token}
```

### Обновлённые endpoints

#### Регистрация (теперь поддерживает role)
```
POST /api/auth/register
Body: { name, email, password, role }
```

#### Вход (теперь возвращает role)
```
POST /api/auth/login
Body: { email, password }
Response: { token, userId, email, name, role }
```

## 💡 Ключевые особенности реализации

1. **Отдельные экраны для учителя и студента** - полная изоляция UI
2. **Автоматический роутинг после входа** - на основе поля `role`
3. **Валидация на бэкенде** - учитель может видеть только своих учеников
4. **Реактивные компоненты** - обновление данных при загрузке
5. **Обработка ошибок** - graceful обработка всех ошибочных ситуаций
6. **Единый класс по умолчанию** - упрощённая версия для MVP

## ⚡ Производительность

- Эффективная загрузка списка учеников (lean queries)
- Кэширование токена в локальном хранилище
- Минимизация API запросов
- Оптимизация рендеринга FlatList для больших списков

## 🛡️ Безопасность

- ✅ Хеширование паролей (bcrypt)
- ✅ JWT токены с истечением (7 дней)
- ✅ Проверка прав на бэкенде (только учитель может видеть учеников)
- ✅ Изоляция данных по классам
- ✅ Удаление токена при выходе

## 🔄 Жизненный цикл сессии учителя

1. **Регистрация** → создание аккаунта с `role: 'teacher'`
2. **Вход** → получение JWT токена
3. **Загрузка кабинета** → получение списка учеников
4. **Просмотр ученика** → получение прогресса ученика
5. **Выход** → удаление токена и возврат на LoginScreen

## 🚫 Ограничения текущей версии

- ❌ Только один класс `default-class`
- ❌ Нет кодов приглашения для присоединения к классу
- ❌ Прогресс только для чтения (учитель не может редактировать)
- ❌ Нет системы уведомлений
- ❌ Нет экспорта отчётов
