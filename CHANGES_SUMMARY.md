## Инструкции по развертыванию

### 1. Запустить бэкенд
```bash
cd backend
npm install  # если нужны новые зависимости
npm start    # или node server.js
```

### 2. Создать тестовые данные (опционально)
```bash
cd backend
node scripts/seedTeacher.js
```

### 3. Запустить фронтенд
```bash
npx expo start
```

### 4. Тестировать
- Откройте приложение в Expo
- Нажмите "Вход для учителей"
- Используйте учетные данные: `teacher@test.com` / `password123`

## Что нужно делать пользователю

1. ✅ **Тестовые данные**: Запустить `node backend/scripts/seedTeacher.js`
2. ✅ **Вход учителя**: Нажать "Вход для учителей" на WelcomeScreen
3. ✅ **Просмотр учеников**: Увидеть список учеников в TeacherCabinetScreen
4. ✅ **Детали ученика**: Нажать на ученика для просмотра прогресса

## Возможные проблемы и решения

### Problem: "Учеников нет в списке"
**Решение**: Запустите `node backend/scripts/seedTeacher.js` для создания тестовых данных

### Problem: "Не вижу кабинета учителя"
**Решение**: 
1. Убедитесь, что вы вошли через "Вход для учителей"
2. Проверьте, что в БД у пользователя `role: 'teacher'`

### Problem: "Ошибка при загрузке прогресса"
**Решение**:
1. Проверьте, что бэкенд запущен и доступен
2. Убедитесь, что ученик в том же классе, что и учитель (`classId`)
