# 🎓 Кабинет учителя - Быстрый старт

## ⚡ Подготовка тестовых данных

Для быстрого тестирования системы учителя создайте тестовых пользователей:

```bash
cd backend
node scripts/seedTeacher.js
```

Это создаст:
- **1 учителя** с 4 учениками в одном классе
- Каждый ученик имеет разный уровень прогресса

## 👨‍🏫 Вход учителя

1. На главном экране нажмите **"Вход для учителей"**
2. Или на экране входа (WelcomeScreen) найдите ссылку **"Вход для учителей"**
3. Введите учетные данные:
   - **Email:** `teacher@test.com`
   - **Пароль:** `password123`

## 📊 Что видит учитель

### В кабинете:
- 📋 Список всех учеников класса
- ⭐ Для каждого ученика виден:
  - Имя и email
  - Количество пройденных уроков
  - Количество выполненных челленджей
  - Общее количество звёзд

### При клике на ученика:
- 📈 Прогресс выполнения уроков (%)
- 📈 Прогресс выполнения челленджей (%)
- 🌟 Звёзды по каждому уроку/челленджу
- 🏅 Полученные достижения
- 🎨 Количество работ в галерее
- 📊 Полная статистика

## 🔄 Как работает роутинг

- **Студент входит** → Переход на MainMenu (главное меню)
- **Учитель входит** → Переход на TeacherCabinet (кабинет учителя)
- При регистрации через обычный экран → Всегда роль **student**
- Для создания учителя используйте **"Создать аккаунт учителя"**

## 📱 Навигация

```
WelcomeScreen (главный экран входа)
├── Вход ученика → LoginScreen
├── Регистрация ученика → RegisterScreen
├── Вход учителя → TeacherLoginScreen
└── Регистрация учителя → TeacherRegisterScreen

TeacherCabinetScreen (кабинет учителя)
└── Клик на ученика → StudentProgressScreen (детальный прогресс)
```

## 🛠️ Технические детали

### Новые endpoints API:

```
GET /api/auth/teacher/class-students
Authorization: Bearer {token}
→ Возвращает список учеников класса учителя

GET /api/auth/teacher/student/:studentId/progress
Authorization: Bearer {token}
→ Возвращает детальный прогресс ученика
```

### Структура User в БД:

```javascript
{
  name: String,
  email: String,
  password: String (хеширован),
  role: 'student' | 'teacher',      // ← новое
  classId: 'default-class',           // ← новое
  progress: {
    completedLessons: [...],
    completedChallenges: [...],
    stars: Number,
    gallery: [...],
    achievements: [...],
    lessonStars: {...},
    challengeStars: {...}
  },
  createdAt: Date
}
```

## ⚠️ Известные ограничения

- Все пользователи в одном классе `default-class`
- Нет системы кодов приглашения для присоединения к классу
- Прогресс ученика только для чтения (из кабинета учителя)
- Нет уведомлений в реальном времени
