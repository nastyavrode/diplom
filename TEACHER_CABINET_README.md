# Кабинет учителя - Инструкция

## Что добавлено

Система управления классом для учителей с возможностью просмотра прогресса учеников.

### Основные компоненты:

1. **TeacherLoginScreen** - вход для учителей
2. **TeacherRegisterScreen** - регистрация новых учителей  
3. **TeacherCabinetScreen** - главный экран кабинета с списком учеников
4. **StudentProgressScreen** - экран просмотра прогресса конкретного ученика

## Как использовать

### Для учителя:

1. На главном экране входа нажмите **"Вход для учителей"**
2. Либо создайте новый аккаунт через **"Создать аккаунт учителя"**
3. После входа вы попадёте в **Кабинет учителя**

### В кабинете учителя:

- Видите список всех учеников класса (пока в одном классе все ученики)
- Для каждого ученика отображается:
  - Имя и email
  - Количество пройденных уроков
  - Количество завершённых челленджей
  - Общее количество звёзд
- Нажмите на ученика, чтобы увидеть детальный прогресс

### Детальный прогресс ученика:

- Статистика: звёзды, уроки, челленджи, достижения
- Прогресс выполнения уроков (%)
- Прогресс выполнения челленджей (%)
- Список звёзд по отдельным урокам
- Список звёзд по челленджам
- Полученные достижения
- Информация о работах в галерее

## Технические изменения

### Backend:

1. **User.js** - добавлены поля:
   - `role`: 'student' или 'teacher'
   - `classId`: класс ученика/учителя

2. **auth.js** - новые endpoints:
   - `POST /register` - поддерживает параметр `role`
   - `POST /login` - возвращает `role` в ответе
   - `GET /teacher/class-students` - получить список учеников класса
   - `GET /teacher/student/:studentId/progress` - получить прогресс ученика

### Frontend:

1. **App.js** - добавлены маршруты:
   - `TeacherLogin`
   - `TeacherRegister`
   - `TeacherCabinet`
   - `StudentProgress`

2. **utils/api.js** - новые функции:
   - `fetchTeacherClassStudents()` - получить список учеников
   - `fetchStudentProgress(studentId)` - получить прогресс ученика

3. **LoginScreen.js** - обновлена навигация:
   - После входа редирект в зависимости от роли (MainMenu для студента, TeacherCabinet для учителя)

## Текущие особенности

- Все ученики и учителя находятся в одном классе `default-class`
- При регистрации ученика через обычный экран - всегда роль `student`
- При входе автоматически определяется тип учетной записи и перенаправляется на нужный экран
