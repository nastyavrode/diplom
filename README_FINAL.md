### Backend (API endpoints)
```
✅ GET /api/auth/teacher/class-students
   → Список учеников класса учителя
   
✅ GET /api/auth/teacher/student/:studentId/progress
   → Прогресс конкретного ученика
   
✅ POST /api/auth/register (обновлено)
   → Поддержка параметра role: 'teacher'
   
✅ POST /api/auth/login (обновлено)
   → Возвращает role в ответе
```

### База данных (User model)
```javascript
✅ role: 'student' | 'teacher'  // Новое поле
✅ classId: string               // Новое поле
```

### Фронтенд утилиты (API functions)
```javascript
✅ fetchTeacherClassStudents()    // Получить учеников
```

## 🎯 Функциональность

### Для учителя
- ✅ Регистрироваться как учитель
- ✅ Входить в систему с учетными данными
- ✅ Видеть список всех учеников своего класса
- ✅ Нажимая на ученика, видеть его подробный прогресс:
  - 📈 Общую статистику (звёзды, уроки, челленджи, награды)
  - 📊 Прогресс по урокам (%)
  - 📊 Прогресс по челленджам (%)
  - ⭐ Звёзды по каждому уроку и челленджу
  - 🏅 Полученные достижения
  - 🎨 Работы в галерее
- ✅ Обновлять данные
- ✅ Выходить из системы

### Автоматизм
- ✅ При входе автоматический перенаправ на кабинет (если учитель)
- ✅ При входе автоматический перенаправ на меню (если студент)
- ✅ Все ученики находятся в одном классе по умолчанию
